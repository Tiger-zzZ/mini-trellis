# mini-trellis v0.4.1 — Antigravity 项目记忆

Antigravity 可以和 Codex、ZCode 使用同一份项目知识。在一个工具里确认规则，在另一个工具里继续开发，规则变化时更新原文。

- `init --antigravity` 安装共享技能与项目 SessionStart，`refresh --antigravity` 更新项目入口。
- 兼容有无 `cwd` 的启动输入，定位到对应项目后加载简短入口。
- 迁移识别 Trellis 清单中的原始 workflow 和技能，保留用户修改和已有知识。

在项目根目录执行，随后在 Antigravity 中开启新会话。

```bash
mini-trellis init -u your-name --antigravity -y
mini-trellis doctor
```

## English summary

Google Antigravity can use the same project memory as Codex and ZCode. Add it with `mini-trellis init --antigravity` to install shared skills and the project SessionStart entry. Startup accepts both workspace-only and `cwd` payloads. Migration uses Trellis template hashes to keep edited workflows and existing knowledge in place.
