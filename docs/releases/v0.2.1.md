# mini-trellis v0.2.1 — Unified recall, lightweight memory

统一检索项目文档与历史对话，关联主题笔记和开发日志，让后续会话按需接续已有知识。

## 用户能感受到的变化

- **统一召回**：`mem recall` 自动查找项目 Markdown 和历史对话，返回出处与短摘录；缺少上下文时用 `mem read` 展开。
- **轻量启动**：会话从短入口开始，规范和研究按需读取，省去首条报到与全量 research 注入。
- **主题与日志关联**：确认结论更新已有主题，开发日志通过相对链接指向详细笔记。
- **记录与诊断**：新安装默认只写文件，升级保留原配置；doctor 展示最近 hook 和记录结果，未观察到真实运行时显示 `unknown`。
- **大目录扫描**：批量检查 Git 忽略规则，缩短文档扫描时间，并保留扫描不完整的提示。
- **Node 18 兼容**：修正启动横幅依赖，使全新安装符合最低运行环境要求。

默认提示词保持英文，新笔记默认使用讨论语言，更新已有文档时保持原语言。检索在本地运行，无需嵌入模型或额外模型服务。

## 升级与核对

升级前请备份项目知识和自定义配置，包括被 Git 忽略的文件。在项目目录运行：

```sh
mini-trellis upgrade
mini-trellis refresh --dry-run
```

检查预览与冲突后应用更新：

```sh
mini-trellis refresh
mini-trellis doctor
```

Refresh 仅更新受管理且未被本地修改的资产，保留知识和自定义配置，冲突项需单独处理。已有 journal 保持原样，相对主题链接用于新记录。完成后开启新会话。

Codex 的项目与 hook 分别检查信任，启用步骤见 [README](../../README_CN.md#支持的工具)。

## 兼容性

- 检索基于关键词、标题与路径匹配。结果不足时，可尝试原文关键词或标识符。
- 按需摘录控制首次检索的输出量。
- Codex 立即恢复会话后执行 compact，下一条模型请求仍可能收到两个短入口。
