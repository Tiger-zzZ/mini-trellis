# mini-trellis v0.3.8 — Kiro、Pi / OMP 与升级自动刷新

本版新增 Kiro 与 OMP 项目知识接入，修复 Pi 记录命令的参数传递，并把当前项目刷新纳入日常升级。

## Pi / OMP

```bash
mini-trellis init -u your-name --pi -y
# 使用 OMP 时选择：
mini-trellis init -u your-name --omp -y
```

在项目根目录启动 `pi` 或 `omp`，用 `/mini-trellis-remember <确认结论>` 记录，下一次会话通过 `mini-trellis mem recall <query>` 召回。Pi 提示模板现在显式传递附加参数；OMP 使用原生 `.omp` 扩展、提示和技能目录，复用同一份启动入口。

已有项目用 `refresh --pi` 更新 Pi 提示，或用 `refresh --omp` 添加 OMP。安装或刷新后新开宿主会话。Pi 可检索本地原始会话；OMP 使用已保存的项目 Markdown，整理对话可提供 Markdown/text 导出。[中文步骤](../using_CN.md#pi-and-omp) / [English setup](../using.md#pi-and-omp)。

## Kiro

```bash
mini-trellis init -u your-name --kiro -y
kiro-cli chat --v3
```

适用于 Kiro CLI V3 和 IDE 1.x。打开项目后按宿主提示信任工作区，新会话通过 SessionStart 加载简短项目入口。`.kiro/skills/` 提供 remember、session-insight、update-spec 三项技能，复用项目中的 spec、research 与 journal。

用 `/mini-trellis-remember` 保存已确认结论，更新同一主题并记录 journal 引用；后续通过 `mini-trellis mem recall <关键词>` 读取。历史整理可直接提供 Markdown/文本材料。compact 后按 `AGENTS.md` 指引读取已保存知识。

`refresh --kiro`、`doctor`、`migrate` 和 `uninstall` 同步支持 Kiro。配置步骤见[中文使用说明](../using_CN.md#kiro) / [English setup](../using.md#kiro)。

## 升级自动刷新

从 0.3.8 开始，在已初始化的项目根目录运行：

```bash
mini-trellis upgrade
```

npm 安装成功后，命令启动新版 CLI 刷新当前项目的技能、Hook 和脚本，保留项目知识与本地修改。刷新遇到冲突时会报告文件及后续命令。未初始化的目录只升级 CLI，其他项目按需运行 `mini-trellis refresh`。`upgrade --dry-run` 预览这两步。

从 0.3.7 或更早版本首次升级时，旧命令仍按原有方式工作，需要再刷新一次：

```bash
npm install -g mini-trellis@0.3.8
mini-trellis refresh --dry-run
mini-trellis refresh
```

以后由 0.3.8 及后续版本执行 `upgrade` 即可自动完成当前项目刷新。通过 npm 直接更新 CLI 时，仍使用 `refresh` 同步项目文件。
