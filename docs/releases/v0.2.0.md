# mini-trellis v0.2.0（发布草案）

> 当前是开发草案。完成 Codex 与 Claude Code 的真实宿主验证后，再创建 `v0.2.0` tag。

## 用户能感受到的变化

- 旧项目执行 `mini-trellis init --claude`、`--codex`、`--pi` 时，会保留原有 AGENTS 和 JSON 设置，只补齐 mini-trellis 的管理块与 hook。
- `mini-trellis doctor` 会检查 `.trellis`、AGENTS 管理块和宿主 hook，并支持 `--json`。
- SessionStart 只注入短摘要，最多 4000 字符；重复触发会跳过已有上下文。
- 注入内容会明确记录时机：确认决策、研究结论、会话结束或 compact；默认只写文件，不自动提交 Git。

## 发布前检查

```bash
pnpm build
pnpm test
pnpm --filter mini-trellis lint
pnpm --filter mini-trellis typecheck
pnpm --filter mini-trellis lint:py
```

完成 Codex、Claude Code 的真实会话验证后，更新本文件和 `CHANGELOG.md`，再创建：

```bash
git tag -a v0.2.0 -m "mini-trellis v0.2.0 — stable host hooks and diagnostics"
```
