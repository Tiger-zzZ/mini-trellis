# mini-trellis v0.2.0

> v0.2.0 已完成本地自动化、打包冒烟和 Codex 真实会话验收。Claude Code 的 hook 脚本契约已验证；当前代理返回 400（要求启用 1m context），因此完整模型 API 回合仍需在代理能力恢复后补验。

## 用户能感受到的变化

- 旧项目执行 `mini-trellis init --claude`、`--codex`、`--pi` 时，会保留原有 AGENTS 和 JSON 设置，只补齐 mini-trellis 的管理块与 hook。
- `mini-trellis doctor` 会检查 `.trellis`、AGENTS 管理块和宿主 hook，并支持 `--json`。
- SessionStart 只注入短摘要，最多 4000 字符；重复触发会跳过已有上下文。
- 注入内容会明确记录时机：确认决策、研究结论、会话结束或 compact；默认只写文件，不自动提交 Git。
