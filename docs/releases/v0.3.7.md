# mini-trellis v0.3.7 — 智谱/Z.ai ZCode 项目知识接入

草稿，尚未发布。2026-11-07。

在 ZCode 中使用同一份项目知识：确认决定后更新原主题并留下 journal 链接，在后续会话用 `mem recall` 找回，缺少条件时再 `mem read`。remember、session-insight、update-spec 均复用现有共享技能，在 `.agents/skills/` 与 Codex 共用同一份文件，避免同名双份加载。

```bash
mini-trellis init -u your-name --zcode -y
```

桌面版在「设置 → 钩子」选择当前项目，审查并信任 `.zcode/hooks/session-start.py` 后新开会话。独立 CLI 用户使用 `zcode hooks trust review` 审查，再授予对应 digest。桌面随包 core 不是完整 TUI，不应直接无参数启动。mini-trellis 不自动授予信任，也不修改用户级配置、模型或 API。详细步骤见[中文使用说明](../using_CN.md#zcode-zai) / [English setup](../using.md#zcode-zai)。

项目配置只注册 startup、clear、compact 的 `SessionStart` 短入口，不增加每轮注入、子代理或任务流程。原有用户 hooks、配置和其他技能保留；非法配置与不安全路径在写入前阻止，refresh 对本地修改报冲突。迁移清理已识别的 Trellis 注册；卸载沿用现有确认与 `.trellis/` 删除范围。

新笔记按指定或讨论语言编写，更新保持原文语言；同主题更新原文件，journal 链接指向实际核验的文件。普通排版修改不产生记忆，新装默认不自动 Git 提交。

本版支持项目文档与用户提供的 Markdown/文本整理，不读取 ZCode 原始聊天。compact 后仍使用已保存的项目知识。

官方桌面 3.17.2（内置 core 0.17.1）、GLM-5.3-Flash 已完成真实核心流程：启动入口送达、显式与自然确认记录、新会话召回、同主题更新、保留前提和否定、普通排版与未确认想法不写记忆。主题、journal/index 与实际链接已核对，全程零自动提交。

宿主限制：该版本完成 `/compact` 后不重新触发 SessionStart；模型确认未收到新入口，但仍收到 `AGENTS.md` 的项目知识指引。resume 新入口未验证，不承诺原始聊天或精确压缩恢复。保留 Trellis 式短入口与按需读取设计，不为此添加每轮注入或全局桥接。以上结果不外推其他构建。

项目记忆的核心效果已验证，以上宿主限制保留在支持范围中。版本仍待发布，尚未执行合并、打 tag 或 npm 发布。
