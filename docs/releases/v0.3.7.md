# mini-trellis v0.3.7 — ZCode 项目知识与历史读取改进

2026-11-09。

## 在 ZCode 中复用项目知识

用 `--zcode` 安装项目启动入口，以及 remember、session-insight、update-spec 三项技能。ZCode 与 Codex 共用 `.agents/skills/` 下的同一份技能。

```bash
mini-trellis init -u your-name --zcode -y
```

桌面版在「设置 → 钩子」选择当前项目，审查并信任 `.zcode/hooks/session-start.py` 后开启新会话。独立 CLI 的配置步骤见[中文使用说明](../using_CN.md#zcode-zai) / [English setup](../using.md#zcode-zai)。

确认决定后更新已有主题并留下 journal 链接；新会话通过 `mem recall` 找回知识，缺少条件时用 `mem read` 展开。历史整理使用提供的 Markdown/文本，已有文档沿用原语言。compact 后按 `AGENTS.md` 指引继续读取保存的知识与技能。

安装与刷新保留用户配置、hook 和其他技能；刷新改变 hook 声明后，在 ZCode 中重新审查。

## 完整读取中文与历史记录

Claude Code、Codex 和 Pi 的 JSONL 历史在分块读取时保留完整 UTF-8 字符，包括中文和 emoji。

遇到格式错误或被截断的事件时，提示来源文件、首个受影响行及数量，保留可读取的记录，并将召回结果标记为 `incomplete`。读取结果可直接用于判断材料是否需要补齐。

## 升级

```bash
npm install -g mini-trellis@0.3.7
mini-trellis refresh --dry-run
mini-trellis refresh
mini-trellis doctor
```

已有项目新增 ZCode 时运行 `mini-trellis init --zcode -y`，完成项目信任后开启新会话。
