# mini-trellis v0.3.7 — 智谱/Z.ai ZCode 项目知识接入

草稿，尚未发布。2026-11-06。

在 ZCode 中使用同一份项目知识：确认决定后更新原主题并留下 journal 链接，在后续会话用 `mem recall` 找回，缺少条件时再 `mem read`。remember、session-insight、update-spec 均复用现有共享技能，在 `.agents/skills/` 与 Codex 共用同一份文件，避免同名双份加载。

```bash
mini-trellis init -u your-name --zcode -y
zcode skills list --cwd . --json
zcode hooks trust review --workspace . --json
```

检查返回的命令和 `.zcode/hooks/session-start.py`，接受后自行授予审查到的 `hookDeclarationDigest`，再开启新会话。mini-trellis 不自动授予信任，也不修改用户级配置、模型或 API。详细步骤见[中文使用说明](../using_CN.md#zcode-zai) / [English setup](../using.md#zcode-zai)。

项目配置只注册 startup、clear、compact 的 `SessionStart` 短入口，不增加每轮注入、子代理或任务流程。原有用户 hooks、配置和其他技能保留；非法配置与不安全路径在写入前阻止，refresh 对本地修改报冲突。迁移清理已识别的 Trellis 注册；卸载沿用现有确认与 `.trellis/` 删除范围。

新笔记按指定或讨论语言编写，更新保持原文语言；同主题更新原文件，journal 链接指向实际核验的文件。普通排版修改不产生记忆，新装默认不自动 Git 提交。

本版支持项目文档与用户提供的 Markdown/文本整理，不读取 ZCode 原始聊天。compact 后仍使用已保存的项目知识。

当前已检查官方桌面 3.17.2（内置 core CLI 0.17.1）的技能发现与项目 hook 审查，使用发行包内的同一份 core 和 Electron 运行时；桌面启动器指向该 core 的 app server。真实模型流程与恢复/compact 送达仍待完成模型选择和 hook 信任后验证，不能外推其他构建。旧版若忽略项目 hooks，可按需使用技能和 `AGENTS.md`。

版本仍待发布；本草稿不表示已经满足合并或 npm 发布验收。
