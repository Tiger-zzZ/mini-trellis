# mini-trellis-core

The `mem` primitives behind the [mini-trellis](https://github.com/Tiger-zzZ/mini-trellis) CLI: list, search and extract past Claude Code / Codex / OpenCode / Pi sessions from their local logs. Nothing is uploaded.

```ts
import { searchMemSessions } from "mini-trellis-core/mem";
```

Most people want the CLI instead: `npm install -g mini-trellis`.
