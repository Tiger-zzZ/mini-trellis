# mini-trellis-core

The `mem` primitives behind the [mini-trellis](https://github.com/Tiger-zzZ/mini-trellis) CLI: discover project Markdown, recall relevant documents and local Claude Code / Codex / OpenCode / Pi conversations together, and read source excerpts on demand. Nothing is uploaded.

```ts
import { recallMem, readMemRefs } from "mini-trellis-core/mem";
```

Most people want the CLI instead: `npm install -g mini-trellis`.
